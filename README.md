# Student Management System

A web-based Student Management System developed to manage student information and related academic records.

## Features

* Student registration and management
* Add, edit and delete student records
* Student search and viewing
* Course management
* Student login system
* Database-driven student records
* CRUD operations

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript

## Project Purpose

This project was developed as a practical web application to demonstrate skills in PHP, MySQL, database management, CRUD operations, and web application development.

## Installation

1. Clone or download this repository.
2. Configure the project in a PHP development environment.
3. Create a MySQL database.
4. Import the project database SQL file.
5. Update the database connection settings.
6. Start the PHP development server or configure the project with a local web server.
7. Open the application in a web browser.

## Database

The application uses **MySQL** as the database management system.
